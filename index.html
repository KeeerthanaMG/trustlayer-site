Install in one command

For Windows and macOS. Requires Node.js 20+ and Python 3.10+ with Tk.

Download v0.1.6SHA-256
npx --yes --package ./keeerthanamg-trustlayer-ai-0.1.6.tgz trustlayer-ai install cursor

Run beside the installer, then restart Cursor and open Agent Chat.

Restart your editor

Open Agent Chat in Cursor. TrustLayer reviews requests before submission.

In Windows PowerShell, use npx.cmd if npx is blocked.
